# 口语问数与页面上下文修复（2026-11-02）

用户报告“你好吗，这个区域有几个图片”误入聊天。本轮修复保持现有Java/Python/MySQL/SQLite结构，不新增训练、RAG或Agent框架。

## 现在的处理顺序

1. 浏览器提交原问题和独立的viewRegion，Java/Python核对区域属于授权批次。页面区域不成为全局隐藏筛选。
2. 区分实际查询、聊天与解释/写作/不执行；问候不覆盖后面的查询，引用的句子不被当成执行指令。
3. 绑定当前页面指代，优先尊重WHU这个区域等显式局部对象；该区域/刚才那个区域继续引用已执行查询，缺少唯一对象则显示原有区域选项。范围下拉框仍是独立物理约束，冲突时澄清。
4. 保守规范数量术语：几个图片/几张影像按成对样本组计数，界面说明单位；不把前几张排名或图片文件/资产数改成样本计数。
5. 模型生成查询要求，再生成SQL。计数任务若错误规划成sample_id明细，先修复计划；内部列名矛盾不作为需要用户补充的业务条件。继续沿用所有只读、语法树、字段、范围和反馈校验。

QLoRA适配器仍仅用于原排名状态更新，本轮改进来自上下文传递、任务理解约束及程序修复，不能写作新的微调准确率提升。
