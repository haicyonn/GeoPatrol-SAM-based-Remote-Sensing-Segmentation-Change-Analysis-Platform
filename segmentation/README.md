# 建筑分割接入统一巡变控制台

变化检测与建筑分割共用 Java 后端和原巡变控制台，主入口为 http://127.0.0.1:8786/ 。
旧8788只跳转到该入口，不提供独立问数、影像或数据库接口。

## 使用

1. 双击 `start_segmentation.cmd`，进入原控制台的“WHU建筑物分割 · SCFP验证子集”批次；使用原课题组账号登录。
2. 在区域卡片进入工作台，沿用“总览／全图总览／检测事实／智能问答／协同复核／报告生成”。分割显示原图、建筑掩膜和叠加图；变化检测显示前后时相。
3. 上传新图：双击 `run_sam_segmentation.cmd` 或进入“账号与批次”，任务类型选“单图建筑分割”，模型选 SCFP / SAM ViT-L，选择一批原图后上传。无需后时相或标签。
4. Java持久化任务，使用已有领取、心跳、重试与共享GPU准入；Python使用冻结发布包真实推理，校验后保存分割结果和掩膜，完整批次发布到同一控制台。
5. 智能问答可聊天，也可查询建筑像素、覆盖比例和连通区域。查询由原 ConversationAssistant → ModelSQL → 查询契约 → SQL校验 → 只读快照执行；分析任务复用原 AnalysisTasks。没有另一套SQL生成器。
6. 协同复核支持“分割可接受／需要修正／暂不确定”和多边形精修，草稿不影响统计，审批后使用新版本；原始预测始终保留。报告按所选范围重新统计，支持Word兼容.doc及分析证据导出。
7. 建筑量试验：直接问“本批建筑量是多少”“哪张图片建筑量最多”“当前图片有多少栋建筑”。建筑量按面积至少10像素的8连通区域估计，保留原始连通区域数、过滤小块数和边界候选数。分割事实页可展开“建筑量计数依据”，查看每个候选的编号、外接框和面积。审批精修后按修正掩膜重算，切回原始预测时恢复原始计数。

可以试：“你好”→“你好吗，这批有多少图片？”→“建筑像素占比最高的5张”→“解释一下占比，不要查库”→“那第二高的呢？”。

## 数据与模型

- 已登记100张WHU验证影像，批次 `4270335f-a3c7-46e4-baa9-bb679d4339fa`，300项影像资产索引；保留原 `segmentation_*` 数据与资产哈希，登记到统一批次目录，没有伪造执行任务。
- 新上传推理由Java管理 `batches`、`sample_tasks` 和执行尝试；数值保存于 `segmentation_task_results`，没有冒充变化检测的 `prediction_results`。
- 对话按认证用户、批次、结果口径及会话隔离；查询时使用发布后的只读SQLite快照。聊天不覆盖查询任务和待确认口径，复核变化会更新版本。
- 模型发布包 `H:/RSAM-Seg-save/scfp_whu500_100_f1_20261112_01`，基础SAM ViT-L与 best_adapters.pth 联合恢复，使用 source_snapshot，1024输入、CUDA BF16、logits回原尺寸、阈值0.5。
- 原验证子集F1 93.858661%、建筑IoU 88.427998%，不是独立测试集或模块消融提升。新用户数据不提供标签时不显示伪造准确率。
- SAM与Qwen共用已有模型服务及GPU准入；SAM执行前释放驻留文本模型，完成后移回CPU，下一次文本请求按需加载Qwen。分割不启用原区域排名QLoRA。

## 统计口径

每行一张单时相影像：`foreground_pixels` 建筑像素，`foreground_ratio` 建筑像素占整图像素比例，`component_count` 原始掩膜连通区域，`estimated_building_count` 建筑量估计值。当前计数版本`cc8-min10-v1`，只过滤小碎片，不拆分粘连建筑；边界候选单独标记，跨图相加未作地理去重。10像素是首版试验阈值，尚未用人工逐栋数量证明计数准确率或改善。原掩膜、覆盖像素及分割F1/IoU不受计数过滤影响。没有前后影像不能回答新增/拆除数量，没有地面分辨率不能换算平方米。原图不作为文本Qwen的视觉输入。

## 保留与退出的代码

`contract.py`、`predict.py`、`repository.py`、`persist.py` 保留冻结模型复现和历史导入能力；正常新数据预测由Java任务入口执行。旧独立UI、SQL和对话实现已移出生产目录，留在 `evaluation/unified_segmentation_20261112/retired` 作为历史记录，完整旧源码另有before.zip备份。旧的Windows直接推理脚本仅留文本记录，不再由正常启动器执行。

`stop_segmentation.cmd` 只停兼容跳转；结束整个统一系统使用 `stop_java_backend.cmd`。
